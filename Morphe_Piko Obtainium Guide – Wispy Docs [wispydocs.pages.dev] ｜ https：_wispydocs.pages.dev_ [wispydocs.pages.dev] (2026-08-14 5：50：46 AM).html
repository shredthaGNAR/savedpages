Morphe/Piko Obtainium Guide

How to use Obtainium to install and update Morphe/Piko apps. The apps are prebuilt on my fork of the ReVanced Magisk Module. A new version of the included apps is created every time a new patch releases. APKMirror and Uptodown are used to source the APKs, using the recommended version. Patches are sourced from their official repositories.

You must uninstall any previously installed patched apps if it shows a conflict error when updating to the Obtainium version for the first time. For YouTube, you can export your settings (Misc section) beforehand and restore them later.

Included Apps

Morphe

  • YouTube, YouTube Music, Reddit, MicroG-RE

Piko

  • Instagram, Twitter (X)

Guide

  1. Install Obtainium
  2. Press the button below and confirm the import:
If the button does not work (Manual Import)
  1. Download the JSON configuration file.
  2. Open Obtainium, then go to Settings → Import/Export.
  3. Tap Obtainium Import and select the downloaded JSON file.
  1. Go to the Apps tab - the included apps should now appear

Obtainium will periodically check for updates and notify you when new versions of the apps are available. Background update checking interval can be adjusted or disabled in settings.

Advanced

To build, patch, or customize apps beyond the default set included for Obtainium, follow the instructions in the ReVanced Magisk Module repository.

Once done, go to Add App in Obtainium and use the URL of your template repo as source.

  • If the repository is private you will need to add a personal access token to Obtainium settings. Make sure the token has Content - Read only permission to your private repository.
If you add a repository URL into Obtainium with multiple APKs, use the Filter APKs by regular expression option.

Troubleshooting

Playback Issues Fix for Youtube and Youtube Music

Complete each step in order, confirming if it worked before moving ahead:

  1. Verify you are using the latest release (including MicroG-RE) by refreshing Obtainium.
  2. Go to YouTube settings → Morphe → Miscellaneous → Spoof video streams → Default client

Select other clients (try all).

  1. If you are logged into a paid YouTube premium account, then you can usually (but not always) turn off Spoof video streams without any problems.
  2. Some users report playback delays were fixed after changing to a custom DNS provider.
  3. Connect a VPN to a different country (try at least 5 different countries).
  4. Use a different YouTube account.
