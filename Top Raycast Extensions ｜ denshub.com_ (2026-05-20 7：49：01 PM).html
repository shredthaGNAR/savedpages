Top Raycast Extensions

I've compiled the top Raycast extensions into convenient tables. Now you can easily find the most popular add-ons without wasting time searching.

Denis Rasulev · Jul 25, 2025
Hacker News Reddit Telegram X (Twitter)

There’s this amazing app called Raycast that successfully helped me replace several paid utilities. I’ve been using it for a long time, and it’s become so integrated into my daily routine work on MacBook that it’s now just muscle memory. It’s strange that Apple couldn’t bring their Spotlight up to this level, but that’s another topic.

If you’re curious why specifically Raycast, then read the article Alfred vs Raycast vs Monarch. There are useful tips on using Raycast there.

Raycast Ecosystem

Raycast’s power lies not only in the app itself and its conveniences. Its additional huge advantage is the developed ecosystem of extensions (add-ons), of which almost 2,000 are available as of this article’s publication date. Thanks to them, you can expand functionality, convenience, add work with third-party applications directly from Raycast, and do many other things.

All these extensions are, of course, present in the official Raycast store. But for me, the problem with this store was that it’s not always obvious how to find the most popular ones, that is, those that are downloaded the most. This is especially relevant when you’re just starting to use this utility and it’s not yet clear what’s important and needed, and what’s not. That’s where collective wisdom usually comes to the rescue 😁.

However, on the official page, it’s impossible to sort extensions by any parameters. Maybe I didn’t find it, but I honestly tried. So now everyone has to either read endless extension reviews, each of which praises their own set, or look for some other methods.

I wanted to simplify this task primarily for myself, and collected all extensions into one file. Below you can find tables that will help you quickly find the most popular Raycast extensions. Then you can figure it out yourself.

Notes

  • To output data from the CSV file into the HUGO article, I had to struggle and develop a special Hugo shortcode for CSV files. I’m already preparing an article from which you’ll learn how to install it, how to use it, what parameters are available there, and so on. It might be useful and help you too.

  • The table currently lacks links to the extensions themselves. I understand that it would be much more convenient with them - click on the extension name and go straight to the official Raycast store or even install it immediately. I’m working on this. For now, if you found an interesting extension, copy its name and find it yourself in the official Raycast store.

  • The data in the table is updated approximately once a month. Sometimes more often, because this is still done manually. There’s already a task in the backlog to write and run an automatic script for updating data. So save the link and check this page more often.

  • The table can be sorted by simply clicking on the column name. You can sort by name, by description (although this doesn’t make much sense), and by number of downloads (this is done by default).

  • If you want, you can download the entire file: raycast-extensions.csv. This file contains more than 2000 Raycast extensions and includes links to their pages and installation.
