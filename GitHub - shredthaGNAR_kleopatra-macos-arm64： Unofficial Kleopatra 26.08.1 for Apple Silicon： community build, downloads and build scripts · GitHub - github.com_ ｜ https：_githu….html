Kleopatra for Apple Silicon

An experimental, unofficial macOS arm64 build of Kleopatra 26.08.1.

Website · Downloads · Report an issue

Install

  1. Install native Apple Silicon Homebrew, if needed.
  2. Run brew install gnupg pinentry-mac in Terminal.
  3. Download the DMG from Releases, open it, and drag the app to Applications.
  4. Open Kleopatra and run Tools → Perform Self-Test.

The app uses /opt/homebrew/bin/gpgconf. Keep Homebrew GnuPG installed. No Craft installation is required to run the packaged app.

For graphical passphrase prompts, add or update this line in ~/.gnupg/gpg-agent.conf, preserving other settings:

pinentry-program /opt/homebrew/bin/pinentry-mac

Then run gpgconf --kill gpg-agent; it restarts when needed.

Status

  • Native Apple Silicon (arm64); not an Intel build.
  • Tested on the builder's macOS 27.2 system only.
  • Startup self-tests passed; compliance check skipped. Encryption reported working by the tester.
  • Ad-hoc signed, not Apple Developer ID signed or notarized. macOS may require approval in Privacy & Security.
  • Community build, not an official KDE macOS release. Keep your existing app as a fallback.

Build and fixes

The scripts/ folder contains the Craft installer, diagnostic script, and final backend repair source.

./scripts/install-kleopatra-arm64.command
# After the installer finishes, quit Kleopatra, then:
./scripts/repair-backend.command

The repair updates the installed app. A DMG generated by the installer before that repair does not include the repair; package the repaired app for distribution.

Fixes applied:

  1. Set a native Homebrew Python default and suspend nounset while sourcing Craft.
  2. Install KIO before MimeTreeParser to satisfy its Qt Quick dependencies.
  3. Give libvpx an explicit arm64 Darwin target to avoid generic GNU linker flags on Darwin 27.
  4. Forward bundled gpgconf to Homebrew GnuPG, avoiding nonexistent KDE CI executable paths.

These scripts use the current KDE Craft recipes and are not a fully pinned, reproducible build environment.

Upstream and source

Kleopatra and its dependencies are maintained by their respective upstream projects. See SOURCES.md for source locations and NOTICE.md for attribution. This repository contains packaging scripts and local changes, not a complete mirror of all bundled dependency source code.
