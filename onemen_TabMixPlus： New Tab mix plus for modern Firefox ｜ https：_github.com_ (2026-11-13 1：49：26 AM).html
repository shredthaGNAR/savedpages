Tab Mix Plus is a very popular legacy extension for the Mozilla Firefox browser that enhances Firefox's tab browsing abilities. It includes such features as duplicating tabs, controlling tab focus, tab clicking options, undo closed tabs and windows, plus much more.

Session Manager feature is not included at the moment since it requires complete rewrite.

If you are interested in keeping Tab Mix Plus working, please donate.

Installation

  1. Legacy extensions loader
    Since Firefox removed the internal component that loads legacy extension, in order to install Tab Mix Plus, or any other legacy extension, you have to install 3rd party helper scripts.

    Full step-by-step instructions, with per-OS paths and screenshots, live in the installation guide

  2. Download XPI

    Download the xpi file from our releases page. If you are using Firefox Beta, Developer Edition or Nightly we recommend using the latest development build (tags with pre or test-build in the title) — see Download XPI.

  3. Install XPI

    Open Add-ons Manager tab (about:addons), click the cog icon and select Install Add-on From File…, or drag and drop the file into the Add-ons Manager page — full details in Install XPI.

Troubleshooting

If Tab Mix Plus stops working after Firefox update was installed or when you try to install Tab Mix you get a message that it appears to be corrupt, follow the troubleshooting steps: reinstall the latest configuration files and utils, clear the startup cache, then reinstall Tab Mix Plus.

Browser Compatibility

Tab Mix Plus is fully compatible with the following browsers:

  • Firefox 128 ESR - Nightly
  • Zen Browser 1.7+
  • Waterfox 6.5.0+
  • Floorp 11.9.0+
  • LibreWolf 122+

Firefox versions prior to 128 ESR are not supported.

For Pale Moon download Tab Mix Plus from here

Configuration

Tab Mix Plus comes with Options window that includes all of its preferences as well as adding user interface to important Firefox hidden preferences. It is recommended that you make all changes to the preference in the options window. The options window is available from the Add-ons Manager or from the Tools menu (unless you turn this option off).
